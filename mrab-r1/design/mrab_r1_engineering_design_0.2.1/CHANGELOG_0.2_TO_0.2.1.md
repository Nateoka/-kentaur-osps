# MRAB-R1: 0.2 → 0.2.1

Основание — неизменный Engineering Design Package0.2 и references/R1_PATCH_0.2.1.md. Это локальный patch, не новый design cycle.

1. R1-PROBE-01 / AUTHORIAL RESEARCH-SCOPE DECISION: OD-02 CLOSED. BOUNDED_EVIDENCE_PROBE и полная evidence/consequence/stop chain согласованы в SPEC/EVAL/PROMPTS/FIXTURE/TRACE/registers. Different labels не создают causal-discrimination entitlement; stronger likelihood-model вне R1. Добавлены три bounded entitlement goldens.
2. R1-REDUNDANCY-01 / CONTRACT CORRECTION: восстановлено EQUIVALENT AND (STRUCTURALLY_MORE_COMPLEX OR MATERIALLY_MORE_EXPENSIVE). Fixed relations B3>B2/B4=true, без score. Equal-compute и cheaper-B3 cases теперь дают structural redundancy; resource advantage сохраняется отдельным finding. Independent comparator findings не стираются слабостью другого baseline. Новый symmetric cheaper predicate использует уже принятый resource margin, не новую метрику.
3. R1-PREP-01 / ENGINEERING DEFAULT: B1/B2 normal PREP exactly one. B3 normal skip только stop/restart controller; B0/B4 none. В schemas/config/feedback/execution_context добавлена явная skip provenance; PREP paths покрывают normal/abnormal/forbidden cases. Abnormal skip остаётся ITT, не normal evidence и не architecture saving; это явное уточнение прежнего blanket infra исключения по новому решению автора.
4. R1-B4-01 / STRONG BASELINE POLICY: сохранены все параметры и правила strengthened0.2 tracker. Нет false profile/loci/update/B3 probe/stop grammar. Golden rules и comparison с parent config проверяются, post-results tuning запрещён без новой protocol version.
5. Metadata: Summary/README адресуют фактический FINAL_VERIFICATION, не копируют старые PASS totals. PRE_SEAL vs SEALED_FRESH_EXTRACTION различаются явно. Final external report реально доставляется рядом с ZIP, с manifest/SHA/CRC/member/read-only checks.
6. Synced canonical sources, R1-CAPABILITY-01, остальные metrics/endpoints и матрицы не изменены. Все45 base0.2 specimen labels сохранены. Отдельный golden migration показывает две намеренные адаптации старых synthetic summaries, обусловленные R1-REDUNDANCY-01.

Полный перечень changed files и hashes — CHANGED_FILES_0.2_TO_0.2.1.json и release manifest. Реальные counts/результаты — FINAL_VERIFICATION, не этот changelog.

Не выполнены и не разрешены этим patch: runtime implementation, calibration, model smoke/pilot, новые baselines/conditions/complexity score, causal discrimination endpoint, доказательство H1. Выход — на независимый финальный аудит.
